# 🎓 Student Management System – Java (Task 34.1)

A simple Java application that manages student information using **Static Concepts** and **Object-Oriented Programming (OOP)**. This project demonstrates how static variables, static methods, static blocks, constructors, and anonymous objects work in Java.

## ✨ Features

- 👨‍🎓 Create student objects using a parameterized constructor.
- 📝 Store student ID, name, and course details.
- 🏫 Maintain a common institute name using a static variable.
- 🔢 Automatically count the total number of students.
- ⚡ Display total students using a static method.
- 🚀 Initialize the application using a static block.
- 🔄 Update the institute name for all student objects.
- 🎯 Create an anonymous object to add another student.
- 📋 Display individual student details.

## 📚 Java Concepts Covered

- **Instance Variables** – Store individual student information.
- **Static Variables** – Share institute name and student count across all objects.
- **Static Methods** – Access class-level data using the class name.
- **Static Block** – Execute initialization code when the class is first initialized.
- **Parameterized Constructor** – Initialize student details during object creation.
- **`this` Keyword** – Refer to the current object.
- **Anonymous Object** – Create and use an object without storing it in a reference variable.
- **Class and Objects** – Create and manage multiple student records.
